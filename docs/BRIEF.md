# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：宫颈癌患者及照护者；含年轻患者生育保留与绝经管理需要

场景：FIGO临床分期决定手术或根治性放化疗路径；年轻患者生育保留手术选择与随访；放化疗后阴道狭窄、淋巴水肿、卵巢功能等长期副作用管理；HPV筛查史与家属预防沟通

核心流程：
1. 选择本机资料目录并导入病理/影像/检验报告
2. 核对候选信息，建立FIGO分期与病理档案
3. 记录治疗路径与放疗长期副作用
4. 整理SCC-Ag趋势与随访问隔
5. 生成复诊准备材料

完成结果：得到来源可追溯、可核对的个人病程档案：FIGO分期档案、治疗路径记录、长期副作用与随访节奏、SCC-Ag趋势、复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first

先读取 docs/DESIGN-PROMPT.md，对齐设计者与研究/取舍原则，再逐项完善SPEC。待补：确认来源、Desktop 版本/平台、原型 hash、当前授权与离线/联网边界。

## 用户新增确认（2026-10-18）

- 与结直肠癌、胃癌、食管癌三个新癌种同批启动，「样板先行+批量」：宫颈癌本轮只到 SPEC 草案。
- 差异化力度定为「中等：共享骨架+专属模块」；不得把同一套分类换名字复用。
- 宫颈癌专属主线定为「FIGO 临床分期与治疗路径（手术/根治性放化疗/系统治疗）+ 生育保留与放疗长期副作用」；可复用卵巢癌的女性中心设计经验但不得照搬卵巢模块。
- 品牌：无专属 Logo，先走青绿+白（teal & white）色系+文字标识（CerviPal 小莲宝，占位名）。
- 参照物同结直肠癌条目。
