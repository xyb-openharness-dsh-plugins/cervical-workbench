# SPEC · 小莲宝 CerviPal 宫颈癌工作台 v0.1

日期：2026-10-18。状态：**草案，等待 G1/G2 审**。样板链路（结直肠癌）确认后复用其工程骨架。

## 0. 三道闸口

同结直肠癌 SPEC §0。本轮只交付 SPEC 草案。

## 1. 目标与非目标

**目标**：让宫颈癌患者（及照护者）回答五个问题：

1. 我的 FIGO 分期（含 r/p 淋巴结标记）是什么？凭什么定的？（**分期**）
2. 我的路径是哪条：手术 / 根治性放化疗 / 系统治疗？走到哪了？（**路径**）
3. 治疗的长期影响（绝经症状、阴道狭窄、淋巴水肿、卵巢功能）现在怎么样、在做什么应对？（**长期影响**）
4. SCC-Ag/细胞学/影像随访节奏如何？（**随访**）
5. 生育、HPV 筛查史、家属预防这些事怎么整理、下次问什么？（**生育与预防**）

**非目标**：不做诊断、不判读细胞学、不做 HPV 疫苗接种建议、不做性健康产品推荐、不做病友社区。

## 2. 产品立场

继承家族 9 条立场（结直肠癌 SPEC §2），宫颈癌补充：

10. **临床分期是医生给的**：FIGO 2018 允许影像/病理参与（IIIC r/p），工作台只记录医生给出的分期与依据，不自算。
11. **性健康信息是私密默认**：阴道狭窄扩张器使用、性交痛等记录默认私密（不进导出，本人显式开放才可分享）。
12. **生育是记录不是承诺**：生育保留手术的可行性与后果由医生给；工作台记录"问了什么、医生答了什么原文"。

## 3. 范围（一期）

| 模块 | 内容 | 差异点 |
| --- | --- | --- |
| 看板 | 定调条 →「现在可以做」→ **放疗长期影响状态卡** → 随访卡 → 接下来/最近变化 | 长期影响卡为特色 |
| 我的分期 | **FIGO 2018 分期档案（含 IIIC1/IIIC2、r/p 标记）**、病理类型（鳞/腺/腺鳞）、会诊 | 临床分期结构 |
| 治疗历程 | **路径三选一（手术 / 根治性放化疗 / 系统治疗）**、手术范围记录（锥切/子宫切除/根治性宫颈切除/淋巴清扫）、**外照射+后装（近距离）疗程**、系统治疗 | 后装是独有字段 |
| **性与生育（专属一级模块）** | 生育状态档案（已育/未育/生育意愿）、**生育保留手术记录（锥切/根治性宫颈切除，含随访要求）**、卵巢功能记录（去势/早衰/激素替代医嘱留痕）、性健康私密记录（阴道扩张器医嘱、症状） | 宫颈癌独有 |
| **放疗与长期影响（专属一级模块）** | 放疗疗程档案（EBRT+后装次数）、**放射性肠炎/膀胱炎事件**、**下肢淋巴水肿记录**、**阴道狭窄与扩张训练记录（医嘱驱动）**、绝经症状记录 | 独有 |
| 检查与指标 | **SCC-Ag（鳞癌）**、血常规、影像、**阴道残端细胞学**、HPV 检测记录 | 细胞学为独有随访项 |
| 病情一图秀 | 治疗节点 + SCC-Ag（数值）+ 长期影响事件（分类节点） | 混合序列 |
| 营养支持 | 进食与体重 / 当下困扰（放化疗期间） | 骨架 |
| 心理支持 | 当下感受 / 身体形象与亲密关系 / **母亲身份与家庭沟通** | 专属子页 |
| 复诊准备 | 复诊节奏 / **细胞学+SCC-Ag+影像三类节点** / 就诊准备 | 骨架+专属 |
| 临床研究 | 2026 线索 / 已收藏 / 入组问题 | 骨架 |
| 设置 | 同骨架 | 骨架 |
| **筛查与预防（在复诊准备内子页）** | 本人 HPV/细胞学筛查史、疫苗接种记录（如有）、家属可讨论问题 | 不设一级页，防变成科普页 |

### 明确不做

HPV 疫苗接种建议、"复发率"概率表述、性健康产品推荐、妊娠可行性判断、病友匹配。

## 4. 信息架构（11 个一级页）

```
看板
我的分期 ── FIGO分期 / 病理类型 / 会诊
治疗历程 ── 路径 / 手术范围 / 放疗疗程 / 系统治疗
性与生育 ── 生育档案 / 生育保留记录 / 卵巢功能 / 性健康（私密）
放疗与长期影响 ── 疗程档案 / 肠膀胱事件 / 淋巴水肿 / 阴道与绝经
检查与指标 ── SCC-Ag / 细胞学与HPV / 影像 / 血象
病情一图秀
营养支持
心理支持 ── 当下感受 / 身体形象 / 母亲身份与家庭
复诊准备 ── 复诊节奏 / 三类随访节点 / 筛查与预防 / 就诊准备
临床研究
```

差异自查：两个专属一级页（其它癌种各一个）；「筛查与预防」刻意降为子页；「性与生育」含私密开关是全家族首个默认私密模块。

## 5. 特有场景

| # | 场景 | 给什么 | 不给什么 |
| --- | --- | --- | --- |
| V1 | 确诊后分期沟通（IIIC 是什么） | 分期档案+依据原文+术语对照 | 不解释"是几期严重不严重" |
| V2 | 年轻未育，生育保留 | 手术记录位+随访要求记录+可讨论问题 | 不判断"还能不能生" |

| V4 | 阴道狭窄扩张 | 医嘱原文+训练打卡记录（私密默认） | 不推产品 |
| V5 | 潮热盗汗（治疗诱导绝经） | 症状记录+激素替代医嘱留痕 | 不推荐用药 |
| V6 | 腿肿（淋巴水肿） | 记录+就诊展示 | 不做分诊 |
| V7 | 女儿/家人问 HPV | 筛查史档案+可讨论问题 | 不给接种建议 |
| V8 | 复发找试验 | 2026 线索+入组问题 | 不排序不预测 |

## 7. 风险

专属页过多（11 个一级页）→ G1 审时确认是否合并；性健康模块让人抵触 → 入口文案中性化+"完全跳过不填"始终可用；生育话题引发情绪 → 心理支持联动入口。

## 8. 术语

FIGO 2018：宫颈癌临床分期体系（含 IIIC 淋巴结分期，r=影像/p=病理）；后装（brachytherapy）：近距离放疗；生育保留手术：锥切/根治性宫颈切除等保留子宫或宫颈的术式；阴道残端细胞学：切除子宫后的随访细胞学。
