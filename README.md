# 小莲宝 CerviPal 宫颈癌工作台

简体中文 · CerviPal Cervical Cancer Workbench

小莲宝（CerviPal，占位名）是面向宫颈癌患者及照护者的 DSH Desktop 本机优先工作台。它围绕 FIGO 2018 临床分期与治疗路径，重点记录生育保留、放疗长期影响（后装疗程、淋巴水肿、阴道狭窄、治疗诱导绝经）与随访节奏。医疗内容只用于资料整理和就诊沟通，不替代医生诊断或治疗意见。

## 产品范围（一期规划）

- FIGO 分期档案（专属主线）：含 IIIC1/IIIC2 细分与 r/p（影像/病理）标记，只记医生给出的分期与依据，不自算。
- 性与生育（专属模块）：生育状态档案、生育保留手术记录（含随访要求原文位）、卵巢功能记录、性健康记录——**全家族首个默认私密模块**（不进导出、不进看板摘要，本人显式开放才变更）。
- 放疗与长期影响（专属模块）：外照射 + 后装次数分列、放射性肠炎/膀胱炎事件、下肢淋巴水肿记录、阴道狭窄扩张训练（医嘱驱动）、绝经症状与激素替代医嘱两列分开。
- 检查与指标：SCC-Ag（鳞癌）、阴道残端细胞学（只存原文，不重判读）、HPV 检测记录。
- 复诊准备：细胞学 + SCC-Ag + 影像三类随访节点；筛查与预防为子页（无疫苗建议表述）。

## 数据与能力边界

- 患者数据必须存入用户明确选择的资料目录；导入文件在本机处理，识别字段先作为候选内容展示，用户核对后才写入病情记录。
- 2026 临床试验资料包按家族统一方法学采集（资料包在样板癌种链路确认后补充）；登记不证明有效、安全或开放入组。
- 临床试验搜索结果是查找线索，不代表符合入组条件；试验状态和入排标准应向研究中心核实。
- 工作台不提供诊断、分期判读、疗效评价或处置建议；用户看法与担心按"一条信息"记录，标注"不是医生结论"。
- 原型中全部数据为虚构演示数据，不是真实病例。

```bash
npm run pack:check # npm 包内容检查，不发布
```
